# MediRoute — Intelligent Hospital Decision Support System

An advanced Hospital Decision Support System (IDSS) integrating route optimization, medical resource allocation, hospital network analysis, clinical multi-criteria decision making, and appointment scheduling.

## System Architecture Overview
- **Task 1: Route Optimization** (A* Search, Dijkstra's Algorithm, BFS Route Planning)
- **Task 2: Medical Resource Allocation** (Greedy Priority Queue Allocation, Hungarian Algorithm)
- **Task 3: Hospital Facility Network Analysis** (Floyd-Warshall All-Pairs Shortest Path, BFS/DFS Topological Traversal)
- **Task 4: Intelligent Decision Support** (MCDA Weighted Ranking, Decision Tree Classification)
- **Task 5: Clinical Scheduling Optimization** (Genetic Algorithm Metaheuristic, Priority Greedy Scheduler)

## Setup & Execution
1. Create and activate a virtual environment.
2. Install dependencies: `pip install -r requirements.txt`
3. Configure `.env` from `.env.example`.
4. Initialize the database and run: `python app.py`
